## 💜 About the Project / Sobre o Projeto

O **Projeto "Entre Elas"** é uma iniciativa de **qualificação profissional** voltada para a promoção da **autonomia econômica e social** de mulheres em situação de vulnerabilidade no **Distrito Federal e entorno**.

O projeto oferece cursos **100% gratuitos e presenciais** em áreas estratégicas da beleza e tecnologia, proporcionando às participantes não apenas capacitação técnica, mas também uma rede de apoio, acompanhamento psicossocial e suporte jurídico para que possam construir uma nova realidade.

> *"Quando uma mulher se transforma, ela move o mundo ao seu redor."* — Manifesto Entre Elas

### 🎯 Público-Alvo / Target Audience

Mulheres em situação de vulnerabilidade social no DF, incluindo:
- Vítimas de violência doméstica
- Mulheres negras e periféricas
- Mulheres com baixa escolaridade
- Mães solo com sobrecarga de tarefas domésticas
- Mulheres em situação de insegurança alimentar

---

## 🎯 Mission / Missão

Enfrentar o desafio da **exclusão econômica e social** que atinge mulheres, especialmente negras e moradoras de áreas periféricas, por meio do:

- ✅ Acesso à **educação técnica** de qualidade
- ✅ Criação de **redes de apoio** reais para geração de renda
- ✅ **Acompanhamento psicossocial** durante toda a formação
- ✅ Caminhos para a **inserção no mercado de trabalho**
- ✅ Estímulo ao **empreendedorismo feminino**

## 🎯 Objectives / Objetivos

- Capacitar cerca de **200 mulheres** em áreas estratégicas da beleza e tecnologia
- Promover a **autoestima e o empoderamento** através de acompanhamento psicossocial
- Facilitar a **formalização de microempreendimentos (MEI)** e criação de identidades visuais profissionais
- Ampliar as oportunidades de trabalho e **reduzir as desigualdades de gênero** na região
- Oferecer **apoio jurídico** sobre direitos fundamentais e proteção legal
- Criar um **espaço de escuta ativa** para conexão entre mulheres com vivências semelhantes

## 📚 Courses Offered / Cursos Ofertados

A formação possui carga horária de **40 horas por curso**, divididas em três turmas para cada eixo:

### 💅 Designer de Unhas
> *Elite Nível I*

A arte do alongamento e estética das unhas com as técnicas mais modernas do mercado. As alunas aprendem desde a preparação da unha natural até técnicas avançadas de nail art e fibra de vidro.

### 👁️ Extensão de Cílios
> *Master Look*

Olhar marcante e natural. Aprenda visagismo e aplicação fio a fio. O curso aborda diferentes volumes, formatos e técnicas para valorizar o olhar de cada cliente.

### ✨ Designer de Sobrancelhas
> *Arquitetura Facial*

Harmonização facial através do design estratégico e henna. As participantes aprendem a analisar o formato do rosto e criar sobrancelhas que valorizam a beleza natural.

### 💻 Informática
> *Digital Pro*

Ferramentas digitais essenciais para gerir seu negócio e crescer online. Inclui pacote Office, redes sociais para negócios, e-commerce básico e marketing digital.

> 📦 As alunas recebem **kits profissionais completos** nos cursos de beleza e utilizam **computadores locados pelo projeto** nas aulas de informática.

## 🚀 Getting Started / Como Executar

### Pré-requisitos

- [Node.js](https://nodejs.org) >= 18
- npm >= 9

### Instalação

```bash
# Clone o repositório
git clone https://github.com/iwerry/EntreElas.git

# Entre no diretório
cd EntreElas

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

O site estará disponível em `localhost`

### Comandos Disponíveis

| Comando | Descrição |
|---------|-----------|
| `npm run dev` | Inicia o servidor de desenvolvimento com HMR |
| `npm run build` | Gera o bundle de produção otimizado |
| `npm run preview` | Preview do build de produção |
| `npm run clean` | Remove o diretório `dist` |
| `npm run lint` | Verificação de tipos com TypeScript |
